# ICOR for Life - Canvases 0.4.1

- Zoom to fit takes your ink in. Core's fit button, Shift+1, the Zoom to fit
  command and Fit to screen now zoom to the cards and the strokes together. A
  canvas with no strokes fits as before.
- A nested canvas in the Daily Scratchpad keeps a dated name. Inside
  `00 Daily Scratchpad` the `<parent> - ` start of the name is locked and you
  name only the rest, so Scaffold Check no longer flags it. Everywhere else
  the whole name stays yours.
- The README says where the breadcrumb sits: the top corner opposite the
  canvas controls, top right by default.

Needs Obsidian 1.13.0 or newer. Copy `main.js`, `manifest.json` and
`styles.css` into `<vault>/.obsidian/plugins/icor-for-life-canvases/`.
