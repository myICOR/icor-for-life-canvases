# ICOR for Life - Canvases 0.3.0

The first public release of ICOR for Life - Canvases: Obsidian's canvas,
the way Heptabase does it. Ink saved in the .canvas file, four tools,
shapes and colours for text cards, canvases inside canvases, a zoom bar
and a minimap, and under every note the canvases it is on and what it
connects to there.

## What is in it

- **Ink.** Pen and eraser with the six canvas colours, three widths,
  undo last stroke and clear all; strokes pan and zoom with the cards; a
  stylus draws without switching tools. Saved in the .canvas file under
  `metadata.icorCanvases` through the canvas's own save path, so undo,
  redo, sync and git carry it.
- **Tools.** Select, Hand, Pen and Eraser (V, H, P, E) in the canvas's
  controls column, with a Group button for two or more selected cards.
  The column sits on the left by default (setting), with the canvas's
  card menu under the tools.
- **Shapes and colours for text cards.** Ten shapes; Outline, Fill and
  Text colour; outline thickness and dash; a frame with corner handles
  on a shaped card; an overflow pill and "Fit shape to text" when the
  text does not fit. Saved on the card as `icorShape` and `icorStyle`.
- **Zoom bar and minimap.** Fit, zoom out, the live percentage and zoom
  in at the bottom right; presets 25, 50, 100 and 200 percent; a
  minimap above the bar (click or drag to move, scroll to zoom, M to
  toggle).
- **Canvases inside canvases.** "New canvas here" in the background
  menu, and a breadcrumb inside a nested canvas back to each parent.
- **Note cards.** Cmd-click (Ctrl elsewhere, or Alt by setting) opens
  the note in the right sidebar; a toolbar on every note card; a pill
  listing the other canvases a note is on.
- **Under every note, and in the Backlinks pane.** The canvases the
  note is on, the groups its card sits in, and every connection with
  its direction and label; a click opens the canvas at that edge.

Every key the plugin writes into a .canvas file is documented in
`docs/canvas-format.md`; other plugins' keys are kept, and a test holds
the plugin to it.

## Fixed before the tag

Flint's reviews of 0.2.0 and 0.3.0 and Tom's live test of the build are
folded in: the editor mark on a styled card survives core's style relay,
the zoom presets stop at core's 200 percent clamp, the zoom bar and the
minimap clear the status bar, flyouts are placed from their anchor's
live rectangle, the contrast fallback no longer flips with the theme,
and a 0.2.0 outline survives the first undo. The full list is in
`CHANGELOG.md`.

## Versions before this one

0.1.0 and 0.2.0 were internal builds, tested by Tom and never published.
The `v0.1.0` tag that sat on the repository belonged to the first of
them and was removed; release tags are bare versions, `0.3.0` onwards.

## Install and compatibility

Needs Obsidian 1.13.0 or newer; verified live on 1.13.7 on a desktop
Mac. Runs on mobile; on a phone the tool group is not shown and the
commands do the same job from the mobile toolbar. From Obsidian's
community plugin directory, or by hand: copy `main.js`, `manifest.json`
and `styles.css` into `<vault>/.obsidian/plugins/icor-for-life-canvases/`.
The core Canvas plugin must be on.

Drawing, the tools, the card toolbar and the shapes read Obsidian's
unpublished canvas object through one module with a runtime check per
member; when an Obsidian update renames one, that feature switches
itself off with a notice and the rest keeps working. The list of members
and how to re-check them is in `docs/architecture.md`.
