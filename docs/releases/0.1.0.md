# ICOR for Life - Canvases 0.1.0

The first release: ink on a canvas, modifier-click to the right sidebar,
a toolbar on every note card, and a list under every note of the canvases
it is on and what it connects to there.

## What it does

- **Ink.** A pencil, an eraser, the six canvas colours plus default, three
  widths, undo last stroke and clear all, in a control group at the bottom
  of the canvas's own controls column. Strokes pan and zoom with the
  cards. A stylus draws without switching the mode on, and its eraser end
  erases. Escape leaves drawing mode. The ink is saved in the .canvas file
  under `metadata.icorCanvases` through the canvas's own save path, so the
  canvas's undo and redo include strokes.
- **Open in the right sidebar.** Cmd-click (Ctrl elsewhere, or Alt by
  setting) on a note card. The same action and "Open in new tab" in the
  card's context menu.
- **Card toolbar.** Two buttons top left on hover and while selected; an
  "Appears in N canvases" pill top right on a note that is on more than
  one canvas, with a menu that opens the chosen canvas at the note's card.
- **Canvases under the note, and a sidebar view.** One block per canvas
  the note is on, with a row per connection: direction glyph, the other
  card's title, the edge label. Click a canvas to open it at the card;
  click a note row to open the note. The index reads every canvas file in
  the vault and follows the vault's events.

## Settings

Open in the right sidebar with (Cmd or Ctrl, Alt), Toolbar on note cards,
Show canvases under the note, Pen colour, Pen width, A stylus always
draws, Debug logging. All in Obsidian's settings search.

## Verified live

On Obsidian 1.13.7 in the development vault on 2026-09-07: the plugin
enables with no console error, the index reports a note on two canvases,
the sidebar view and the footer render the rows, the toolbar is in the
DOM of a note card, and a stroke drawn in drawing mode is in the .canvas
file after the save. See `docs/architecture.md` for the private surface
this depends on and how to re-check it on the next Obsidian release.

## Not verified

"Export as image" with ink present; Apple Pencil on an iPad; a canvas in
a pop-out window; Obsidian builds older than 1.13.7.
